# EventMate - Collaborative Event Manager

This project is a collaborative event management application built with React, TypeScript, Vite, Firebase, and Material UI. It allows users to create, manage, and share events.

This application was refactored from an initial "Spoty" music template to implement the core features of "EventMate".

## Core Technologies

-   **React 19** with Hooks
-   **TypeScript** for type safety
-   **Vite** for a fast development experience
-   **Firebase** for Authentication, Firestore (database), and Cloud Storage
-   **Material UI** for the component library
-   **React Router** for client-side routing

## Getting Started

1.  **Clone the repository.**
2.  **Create a `.env.local` file** in the root directory and add your Firebase project configuration variables (e.g., `VITE_FIREBASE_API_KEY`, etc.).
3.  **Install dependencies:** `npm install`
4.  **Run the development server:** `npm run dev`
